# Предметная область
Нашей информационной системой является система по сбору, хранению и агрегации отзывов студентов о преподавателях университета ИТМО. Данная система нацелена на сферу образования и ставит перед собой задачу помочь студентам выбрать преподавателя под свои интересы и цели.

# Цели информационной системы
Предложенная информационная система ставит перед собой цель покрыть полный цикл получения, обработки и использования релевантной для данной системы информации, что включает в себя следующие этапы:
1. Проведение автоматизированного сбора информации о преподавателях (ФИО, табельный номер, фотография) из соответствующих открытых ресурсов с последующим ее хранением в единой базе данных.
2. Предоставление возможности студентам оставлять свои комментарии и оценивать преподавателей по заданным системой параметрам.
3. Предоставление удобных инструментов для поиска, фильтрации и анализа собранной информации пользователям системы.

# Функциональные требования

## 1. Главная страница
1.1. Должна содержать название и описание информационной системы<br>
1.2. Должна содержать кнопки перехода на страницу поиска и на страницу оценивания

## 2. Страница поиска
2.1. Должна содержать строчку поиска по ФИО. Поиск должен производиться по любой из частей ФИО<br>
2.2. Должна содержать выпадающий список фильтрации по тегам. Напротив каждого тега нужно указывать количество людей, которым этот тег принадлежит<br>
2.3. Все используемые теги должны быть указаны под строчкой поиска с крестиком (т. е. с возможностью удаления)<br>
2.4. Результаты поиска в отображаются в виде карточек. Карточка содержит фотографию, ФИО, табельный номер, средний рейтинг и теги преподавателя (если теги не вмещаются в карточку, должна быть отображена только часть из них + должно быть отображено количество тегов, которые не поместились)<br>
2.5. Максимальное количество карточек на странице - 40 штук<br>
2.6. Снизу страницы должна быть пагинация со следующими кнопками: вперед и назад<br>
2.7. Также должно быть отображение текущей страницы (с возможностью ручного ввода для смены страницы) и отображением максимального количества страниц<br>
2.8. При нажатии на карточку должен производиться переход на страницу с отзывами

## 3. Страница с отзывами
3.1. Должна отображать фотографию, фио, общий средний рейтинг, а также средний рейтинг по каждому из заданных системой параметров<br>
3.2. Должна отображать все теги<br>
3.3. Если человек оставлял отзывы, его отзыв должен быть показан отдельно, над всеми остальными отзывами + должна быть кнопка удаления отзыва (иначе должна быть надпись "вы не оставляли отзыв о данном преподавателе")<br>
3.4. После нажатия на кнопку удаления отзыва должно появляться модальное окно с подтверждением<br>
3.5. Должна отображать текстовые отзывы с указанными оценками и датой публикации<br>
3.6. Отзывы должны быть отсортированны по дате публикации, начиная с новых<br>
3.7. Максимальное количество отзывов на странице: 10, пагинация должна работать аналогично пагинации на главной странице<br>
3.8. Должна содержать кнопку перехода на страницу оценивания

## 4. Страница оценивания
4.1. Должна содержать следующие поля: выпадающий список ФИО или табельного номера (если переход был осуществлен со страницы отзывов, то эти данные должны быть выставлены автоматически) с возможностью поиска, год обучения у преподавателя, предмет, текстовый комментарий, поля оценки (общее впечатление, сложность обучения, интересность преподавания, организованность, справедливость оценивания), где слева и справа от оценок будет указано от чего к чему идет оценка (например легко - тяжело, неинтересно - интересно)<br>
4.2. Должна быть возможность добавить теги (существующие или создать новый)<br>
4.3. Должна быть кнопка публикации отзывов, после её нажатия человек переадресуется на страницу отзывов, где его отзывов подсвечивается в течении короткого времени
